# Taste

- Prefers larger, highly visible notification/toast UI with prominent redesigned styling over small compact toasts. Confidence: 0.8
- Expects UI state such as cart counts/badges to persist across page reloads and navigation and reflect existing server state on first load, not only after in-page actions. Confidence: 0.85
- Prefers UI cards/popups with generous internal padding so inner content never touches borders; calls out cramped edge-touching layouts as looking odd. Confidence: 0.85
- Wants changes scoped and surgical: make the requested tweak and explicitly leave everything else untouched ("don't modify or touch anything else"). Confidence: 0.75
